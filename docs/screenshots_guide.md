# Screenshot Capture Guide 📸

To present this project professionally on GitHub, capture the following screenshots from your browser while running the application locally. Save them in this directory (`docs/screenshots/`) with the filenames below. You can then reference them in your root `README.md`.

## Recommended Screenshots to Capture

1. **`01_register_page.png`**
   * *Capture*: The registration screen (`http://localhost:5173/register`).
   * *What to show*: The custom theme color selectors for avatars and the clean validation styling.

2. **`02_login_page.png`**
   * *Capture*: The sign-in interface (`http://localhost:5173/login`).
   * *What to show*: A sleek email/password card with the CommSphere logo.

3. **`03_dashboard_feed.png`**
   * *Capture*: The primary forum feed page (`http://localhost:5173/`).
   * *What to show*: Seeded discussions, category search pills on the sidebar, active platform stats, and the topic search bar.

4. **`04_create_discussion.png`**
   * *Capture*: The topic creation form (`http://localhost:5173/create-discussion`).
   * *What to show*: Form entries for Title, Category drop-down, Details content, and Tag listings.

5. **`05_forum_discussion_mode.png`**
   * *Capture*: The discussion details page (`http://localhost:5173/discussion/<id>`) on the **Forum Discussion** tab.
   * *What to show*: Original topic content, creator tag, and threaded comments.

6. **`06_live_chat_mode.png`**
   * *Capture*: The same discussion detail page toggled to the **Live Chat Room** tab.
   * *What to show*: Split UI with live message bubbles, typing indicators ("User is typing..."), and the list of active online users in the room.

7. **`07_profile_settings.png`**
   * *Capture*: The profile settings page (`http://localhost:5173/profile`).
   * *What to show*: Dynamic changes to the bio, avatar colors, and save indicators.

8. **`08_database_compass.png`**
   * *Capture*: MongoDB Compass or MongoDB Atlas interface.
   * *What to show*: Collections (`users`, `discussions`, `comments`, `messages`) representing the schema tables.
